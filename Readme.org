* OrderedMap nodes

The nodes of the B+ tree behind Bjolang's ~(std orderedmap)~. The tree itself
(descent, splits, merges, iteration, transients, builders) is written in
Bjolang, in ~lib/std/orderedmap.bjo~.

- ~Nodes.cs~: a leaf holds its keys and values in two arrays of 64. An
  internal node holds 32 keys and 32 children in inline arrays, which Bjolang
  cannot declare.
- ~NodeOps.cs~: the operations on one node, or between the slots of two,
  that the Bjolang tree calls.
- ~BTreeFunctions.cs~ and ~Scanners.cs~: the key search in a node. Primitive
  numeric keys are searched with vector instructions; other keys by binary
  search with the comparer.
- Copy-on-write: a node records its owner. A transient edits the nodes it
  owns in place and copies the rest.
